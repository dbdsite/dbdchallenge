# DBD CHALLENGE — русская версия

## Что изменено

### Полностью русский интерфейс
Основные экраны, кнопки, статусы, подсказки и история переведены на русский язык.

### Новая система открытия перков

Теперь **каждый из 4 перков открывается отдельно**.

Для текущего перка сайт задаёт вопросы, пока не выполнится одно из условий:

- **2 правильных ответа** → открывается хороший перк;
- **2 неправильных ответа** → открывается плохой перк;
- если было `1 правильный + 1 неправильный`, вопрос продолжается;
- количество вопросов не фиксировано и может быть больше 9.

После выбора ответа правильный вариант и ошибка игрока остаются подсвеченными 2,5 секунды. Только после этой паузы открывается следующий вопрос или экран полученного перка.

После открытия перка появляется отдельный экран:

**ПЕРК ОТКРЫТ → изображение → название → описание → ПРОДОЛЖИТЬ**

После кнопки `ПРОДОЛЖИТЬ` начинается набор вопросов для следующего перка.

После открытия 4-го перка показывается общий билд из четырёх перков, как раньше.

### Общий банк вопросов

После выбора режима и ввода ника челлендж начинается сразу. Все категории входят в общий банк, а сложность выбирается с весом текущего уровня. Внутри одного полного цикла вопрос не повторяется; после исчерпания банка начинается новый цикл.

## Папки для PNG

```text
assets/
├── perks/       ← PNG перков
├── icons/       ← иконки интерфейса
├── backgrounds/ ← фоны/текстуры
├── logo/        ← логотип
└── sounds/      ← звуки
```

Пути к изображениям перков находятся в `data/perks.js`.

Например:

```js
image:"assets/perks/sprint-burst.png"
```

Если PNG ещё не положен в папку, сайт автоматически оставит текстовый значок перка.

## Важное
Сейчас в `data/questions.js` и `data/perks.js` находится демонстрационный набор данных. Его можно расширять без переделки логики.


## Сохранение прогресса и продолжение

У каждого прохождения теперь есть отдельный `challengeId`.

После повышения уровня:
- прогресс автоматически сохраняется;
- кнопка **СОХРАНИТЬ И В МЕНЮ** возвращает на главный экран;
- в **ИСТОРИИ ЧЕЛЛЕНДЖЕЙ** активный челлендж получает кнопку **ПРОДОЛЖИТЬ**;
- продолжение восстанавливает уровень, игроков, открытые перки и текущую стадию.

Челлендж становится недоступным для продолжения, если:
- пройден максимальный уровень 15;
- получено второе поражение.

Первое поражение с проклятым билдом оставляет челлендж активным.

## Разделение перков

Есть четыре независимые категории:

- `killerGood` — хорошие перки убийцы за 2 правильных ответа;
- `killerBad` — плохие перки убийцы за 2 неправильных ответа;
- `survivorGood` — хорошие перки выживших за 2 правильных ответа;
- `survivorBad` — плохие перки выживших за 2 неправильных ответа.

Категории находятся в `data/perks.js` и используются автоматически в зависимости от выбранной роли.

## Начало работы над отдельной копией

Эта папка — рабочая копия исходного проекта. Откройте `index.html` в браузере для локальной проверки.

- Сохраняется текущий этап прохождения: вопрос, открытый перк, готовый билд, готовность команды, ввод результата матча или экран результата.
- Текущий вопрос и порядок его ответов сохраняются. После возвращения вопрос не засчитывается повторно.
- Если вкладка закрыта сразу после ответа, отложенная выдача перка завершается при продолжении.
- После полного прохода по вопросам начинается новый перемешанный круг. Внутри одного круга повторы исключены.
- Порядок вариантов ответа теперь перемешивается для каждого вопроса.

Данные вопросов и перков пока не переработаны. Результат матча по-прежнему вводится вручную; сохранение хранится только в браузере на данном устройстве.

Отдельный файл `data/map-questions.js` добавляет 46 вопросов по картам: 45 с локальными изображениями и один текстовый вопрос об исходной карте полицейского участка Раккун-Сити. Все варианты ответов для карт написаны по-русски.

Файл `data/structure-questions.js` добавляет 13 визуальных вопросов категории **КОНСТРУКЦИИ**: лабиринтные тайлы, L–T-стены, джангл-джим, четырёхстенка, тайл со шкафчиками, лабиринтный и вариативный тайлы. Все вопросы используют локальные фотографии конструкций.

Все вопросы о правилах самого приложения собраны в категории **ЧЕЛЛЕНДЖ**. К ней относятся выдача перков за ответы, повтор вопросов, дополнительная попытка, изменение уровня, правила пати и действия с отсутствующим перком.

## Лор и сложность

Файл `data/lore-questions.js` содержит 216 вопросов категории **ЛОР**:

- 98 лёгких вопросов на определение каждого доступного персонажа по портрету;
- 98 сложных вопросов, минимум один по биографии каждого персонажа;
- 20 средних вопросов об общем лоре игры.

Всего в банке 606 вопросов: 162 лёгких, 261 средний и 183 сложных. На уровнях 1–5 веса составляют 65% / 25% / 10% для лёгких, средних и сложных вопросов; на уровнях 6–10 — 20% / 60% / 20%; на уровнях 11–15 — 10% / 25% / 65%. Внутри каждого полного цикла конкретные вопросы не повторяются. Портреты персонажей и визуальные вопросы по перкам имеют пониженный вес и не выдаются подряд, если в выбранной сложности остались другие вопросы.

Файл `data/expanded-questions.js` добавляет 186 вопросов: 44 по силам всех актуальных убийц, 48 визуальных вопросов по перкам, 20 вопросов по контрплею и 74 вопроса по статусам, предметам, улучшениям, подношениям, интерфейсу, картам, конструкциям, ситуациям, командной игре, погоням и истории игры. Шесть ситуационных вопросов используют локальные игровые изображения конструкций. Аудиовопросы в банк не включены.

Один и тот же перк теперь не повторяется в рамках челленджа, пока не будет исчерпан соответствующий пул хороших или плохих перков выбранной роли. Это правило действует и для обычной выдачи, и для дополнительной попытки с плохим билдом.

Все 15 уровней являются игровыми: победа на уровне 14 открывает уровень 15, а победа на уровне 15 завершает челлендж. Пулы выданных перков не сбрасываются при переходах между диапазонами сложности 5/6 и 10/11; каждый пул перемешивается заново только после полного исчерпания.

`data/question-quality.js` убирает повторы вопросов о правилах челленджа, исправляет формулировки в соответствии с фактической логикой и балансирует длину вариантов ответа.

## Статус перков по пикрейту

`data/perk-pickrates.js` хранит статистический снимок и заново формирует четыре пула при запуске. Для каждой роли медиана делит отслеживаемые перки на две группы: пикрейт не ниже медианы означает хороший перк, ниже медианы — плохой. В карточке перка показываются его пикрейт и медиана роли.

## Управление историей

Каждая запись истории получила кнопку **УДАЛИТЬ**. Можно удалить отдельный завершённый или активный челлендж, не очищая остальные записи. Удаление текущего активного прохождения также завершает его локальное состояние.
